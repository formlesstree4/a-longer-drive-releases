# A Longer Drive

Get the game from the [latest release](https://github.com/formlesstree4/a-longer-drive-releases/releases/latest):

- **Windows:** download `ALongerDrive-win-Setup.exe` and run it.
- **macOS** (Apple Silicon, macOS 11 or later): download `ALongerDrive-osx-Setup.pkg` and open it. The first time, macOS blocks it: open it again from System Settings › Privacy & Security › Open Anyway.
- **Linux** (x86-64): download `ALongerDrive.AppImage`, make it executable (`chmod +x ALongerDrive.AppImage`) and run it.

The game keeps itself up to date after that.
